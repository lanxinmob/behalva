# 需求与权限

## 产品目标

一个独立于桌面聊天窗口运行的个人助手。能持续收集与目标有关的信息，索引个人资料，提出下一步，准备材料，执行经过批准的外部操作，并保存可阅读、可修改的经验。

首版按单人自托管设计；未来的开源用户可配置不同的目标、来源、模型和工作流，不以招生专用软件定位。

## 首个工作流

1. 从公开网站和获准来源发现当前信息以及近三届历史资料。
2. 去重、关联上下文，提取条件、时间、材料、费用与培养信息，保留来源和版本。
3. 结合个人档案筛选机会；事实、历史经验、匿名线索和模型判断分别标注。
4. 生成关联的项目、人员或团队、个人材料、申请进度四张表，支持 Markdown 与 Excel 导出。
5. 在手机上追问缺失信息，生成草稿、材料清单、邮件和表单内容。
6. 展示实际收件人、正文、附件、表单字段及目标站点，取得确认后发送或提交。
7. 核验结果并归档。无法确认时标为结果待核实，不盲目重试。
8. 提出可复用流程与纠正规则，用户批准后在新会话和其他任务中应用。

## 资料与来源

- 本机文档、笔记、个人申请材料、项目源码。允许在 C、D 盘自动发现，默认排除系统、依赖、缓存、构建产物和凭据。扫描范围不等于云端使用授权。
- GitHub 公开与私有仓库用于提炼项目经历；学习记录、复现、独立成果不得混淆。
- 网站涵盖官网、院系通知、人员主页、公众号、小红书、知乎及论坛等文字来源。需要登录时使用用户手动登录的专用浏览器。
- QQ 使用日常账号，按群授权。覆盖文字、图片、合并转发、群公告与群文件；历史范围在每个来源接入时设置。
- QQ 群批准后可持续读取，按任务需要交给云端模型，直到撤销。撤销只停止新采集；已存资料仍可检索和交给模型。
- 微信第一版通过分享、粘贴或文件导入，不自动同步。
- 图片与扫描件的 OCR 路径作为技术验证项；B 站视频来源暂不做。

普通私人文档先在本地建立索引，首次交给云端模型时按文件或目录确认。已明确允许的资料类别与文件范围单独记录，不能自动推广为全盘外发授权。远程 embedding、重排、OCR 也属于云端处理，遵守同一权限。

保留网页正文、抓取时间、必要截图与被引用版本或片段。资料更新后更新索引，过去的结论仍能定位当时证据。未取得全文、缺失历史、断线区间和失效附件均显示覆盖缺口。

## 权限

| 操作 | 规则 |
|---|---|
| 已允许范围内的读取、联网检索 | 自动执行 |
| 专用工作目录内的索引、任务状态、草稿与工作记录 | 自动更新 |
| 脚本运行 | 可自动运行，但脚本产生的修改、删除、外发等效果仍遵守对应审批 |
| 原始文件的修改、移动、删除 | 用户确认后执行 |
| 普通私人文件的首次云端使用 | 文件或目录授权后执行 |
| QQ 群资料采集及模型处理 | 已批准群范围内自动执行 |
| 发消息、发邮件、提交表单 | 展示具体内容并逐次确认 |
| 规则或技能生效 | 提出变更，用户批准 |
| 助手自身代码改进 | 可自主开发；两名独立 Agent 审查并经用户确认后启用 |
| 付款 | 第一版不实现 |

外部网页、群消息、附件和检索结果是资料，不能授权工具操作、改变权限或自行安装规则。群成员的命令不等于用户指令。

## 手机

- Kotlin Android 独立 App，以工作台为首页：待办、待确认、长期目标和新发现。
- 对话用于下达任务、追问和解释；支持其他 App 分享链接、图片、文件，不做语音输入。
- 本机关机时可查看已同步表格、任务、草稿和选定材料，编辑草稿与暂存任务。
- 离线编辑冲突由用户选择版本，不静默覆盖。
- 支持锁屏通知，默认只显示“助手有新消息”。通知接入方式需真机验证。
- 登录、短信验证和验证码可通过 App 接手本机浏览器的同一会话，用户交回后继续。
- 用户愿意配合安装测试版、配置必要权限并参加真机验收。

## 长期目标与预算

目标具有优先级、阶段、下一步和关联资料；调整目标、优先级或放弃路线由用户决定。定期回访并建议下一步，具体提醒频率、免打扰与历史采集范围在使用情境中询问。

优先处理临近截止和待处理操作，其次调查与资料整理，最后自开发新功能。模型使用云端服务，模型名称可配置。较便宜的模型用于筛选与提取；困难或重要事项可升级。

初期周预算约 50 美元，包含任务、编码与审查 Agent。接近额度时暂停非紧急任务、适当降级并询问是否追加；没有追加答复不等于允许超支。到达额度后保留本地提醒、查看和已有状态恢复，新的收费调用等待额度或批准。

## 自修改

发现改进点或新能力需求 → 独立分支或工作树开发 → 针对性验证 → 两名独立 Agent 审查 → 修复并复核 → 展示最终差异和影响 → 用户确认 → 启用 → 健康检查与必要回退。

审查与批准绑定具体版本；代码再变化就失效。代码回退与数据迁移回退分别设计，不把 Git 回退视为完整恢复。公开发布与推送不包含在本地启用批准内。
