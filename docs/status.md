# 实现与验证状态

2026-10-14，开发候选。本文不构成首版通过声明。

## 可运行部分

- 网页与 Android 使用引导、连续聊天及历史选择；手机离线保存输入和待发送消息。
- 电脑供应商表单：名称、API Key、请求地址，获取模型列表、编辑与切换即时生效。默认自动估算预算，无需填单价；高级项可选手动报价。估算不是实际账单或扣费上限。密钥加密存储，不参与设备同步，旧环境变量配置仍支持。当前 Windows 模拟上游测试，不代表真实账号联调。
- 界面候选改用桌面分组导航、手机抽屉/原生四个底部入口，聊天独立滚动与固定输入区；异步同步保护正在输入的文字、焦点和阅读位置。
- 手机连接页展示实际配置位置及自签名指纹，提供 Tailscale 私人 HTTPS 步骤；电脑一次签发设备连接配置，手机粘贴后核对导入，不再必须逐项手填。网络与 Tailscale 安装仍需完成，不能将配置生成当作实际连接成功。
- 聊天转调查任务保留当时的讨论快照；功能需求进入待开发列表，不执行代码。
- C++/SQLite 单实例服务：任务、资料版本、云端授权、检索和原文行定位。
- Android 离线任务和草稿队列、人工冲突选择、资料缓存、分享文件、附件选择。
- 网页工作台、手机设备令牌创建与撤销、HTTPS 和证书指纹验证。
- OpenAI Responses / Chat Completions 文本请求、预算预留、同请求去重、已付费结果与草稿同时持久化。
- 模型结果未知时禁止自动重试；所有者说明核查结果并确认可能新增费用后可批准再次调用，原费用预留保留。
- 邮件完整载荷审批、附件摘要绑定、执行结果未知后查询已发送回执。
- 本机专用浏览器人工远控，命令绑定会话和截图；队列输入不重放。
- C++ 定期调查与追问调度、网页与 Android 管理入口，未回答的追问合并，不积压重复任务。
- 分享的文字、PDF 与 DOCX 附件本地抽取为可检索资料，默认不授权云端使用；图片尚无 OCR。
- 规则批准、可读文件手工纠正记录、数据库一致备份。
- 本机文件消失、清空或无法解析时标记当前不可用，退出默认检索与模型上下文，历史原文仍可读取。扫描根失联或遍历失败不会被误判成全部资料删除。
