## 本次确定

采用 C++ 核心、Kotlin Android 客户端、SQLite 主库与手机离线库；允许通过独立进程使用其他语言的成熟工具。允许使用已安装的 WSL2，实际进程部署位置经过验证后确定。

第一版连通资料发现、来源核验、个人条件匹配、材料准备、手机追问与审批、实际发送或提交、结果核验和归档。支持长期目标与经过批准的规则成长，并具备受审查和人工批准约束的自修改能力。

暂不包含付款、语音输入、B 站视频采集、微信自动同步和 GitHub 代码变动持续跟踪。

## 文件边界

本目录面向未来公开仓库，使用通用描述。用户真实背景另存于私人目录。已初始化本地 Git；没有公开推送。运行工作区、浏览器状态和凭据均在私人目录，不进入本仓库。

后续公开仓库保存实现、通用规则和虚构样例；独立私人仓库保存个人档案、配置、批准后的规则与记忆，默认不推送。数据库、附件、浏览器状态和密钥不进入公开仓库。
